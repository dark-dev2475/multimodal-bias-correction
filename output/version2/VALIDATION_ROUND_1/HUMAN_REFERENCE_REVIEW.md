# Human reference review — all 40 images

**Nothing in this packet is human-approved.** The initial drafts were AI-assisted. A person must inspect the image and supplied context before approving or correcting them.

Review references without viewing method answers. Do not infer beliefs, diagnosis, ability, occupation or character from appearance. Identify which facts are actually necessary to answer the question; decorative details need not be required. Unsupported-inference lists must not contradict the proposed reference answer. Mark uncertainty when identity/attribution is missing.

In each JSON fill decision (approve_as_is or revise), reviewer, reviewed_at (ISO date/time), and attestation with the exact string personally_reviewed_image_and_context. For revise, fill revised_reference using the same schema as reference_draft. Leave these fields unset until an actual person has reviewed the case. No software can verify a reviewer identity.

Use scripts/validate_human_reference_packet.py to check a completed packet. Corrections belong to a new reference version; the old frozen experiment stays unchanged.
